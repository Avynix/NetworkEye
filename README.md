# NetworkEye

A multithreaded TCP port scanner written in Python with hostname resolution, open-port detection, and basic banner grabbing.

## Features
* Accept port range
* Uses threads for faster scan
* Simple

## Requirements
* Python 3.x
* It requires queue, threading, and IPy library

## Use

It asks for hostname/IP, you enter the target
You wait until it complete scan
it will display the open ports

```bash
python networkeye.py
```
